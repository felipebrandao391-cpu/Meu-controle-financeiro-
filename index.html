Dados e segurança

Esta versão guarda os dados neste navegador e neste aparelho. Não há sincronização, login nem backup automático. Se limpar os dados do Safari ou trocar de aparelho, os registros podem ser perdidos.

Os avisos de vencimento aparecem no Painel quando você abre o aplicativo. Notificações automáticas do iPhone ainda não estão ativadas. Use dados fictícios para testar.
